## Installer types

| Platform | Installer | When to use it |
| --- | --- | --- |
| Windows | `*-setup.exe` | Default choice, NSIS installer |
| Windows | `*_x64_en-US.msi`, `*_x64_zh-CN.msi` | When MSI distribution is required, such as enterprise deployment |
| macOS | `*_aarch64.dmg` | Apple Silicon (M-series) |
| macOS | `*_x64.dmg` | Intel |
| Linux | `*_amd64.deb` | Debian, Ubuntu, and similar distributions with fuller system integration |
| Linux | `*_amd64.AppImage` | No installation required, runs as a single file |

## System requirements

| Platform | Requirement |
| --- | --- |
| Windows | Windows 10 or later |
| macOS | macOS 10.15 or later |
| Linux | Modern 64-bit distribution |

The first launch requires a network connection: the app downloads a compatible Node.js runtime and a prebuilt Harness core. Built-in plugins require Harness core **0.1.5-rc.1** or later.

<Note>
  Installers come directly from GitHub Releases; this page neither mirrors nor caches files. A scheduled workflow in this repository syncs the version list from the release page, so it can lag by up to an hour; treat the [release page](https://github.com/dsh-tauri-desk/deepseek-harness-desktop/releases) as the source of truth.
</Note>
