---
title: Remote connections (legacy SSH plugin)
description: The legacy SSH plugin has been replaced by DSH Tauri Remote.
---

`dsh-tauri-ssh` is no longer in the built-in inventory. `dsh-tauri-remote` now provides SSH connections and sync through Harness **Settings → Remote access**.

Continue with the [Remote access plugin](./dsh-tauri-remote), or see [Mobile remote access](../guides/mobile-remote-access) to connect a phone to this computer.
