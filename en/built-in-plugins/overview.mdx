The desktop currently ships 13 first-party plugins as resources. Startup checks restore missing or inconsistent copies.

<Note>
  The recommended core is **0.2.1-rc.5**, and the declared compatibility minimum is **0.2.1-rc.1**. Built-in plugins all require `dsh >= 0.2.1-rc.1`; a locally installed core below that minimum is not activated.
</Note>

## Distribution and permissions

- The current desktop `plugins.built-in` manifest is authoritative; `dsh-tauri-kernel`, `dsh-tauri-ssh`, and others moved to the `depercated` list and are no longer shipped.
- Community presets are installed separately; the Extensions plugin tab is only an entry point to the Harness built-in plugin page and has no marketplace.
- The plugin marketplace comes from the `dshmarket` preset, not a built-in capability.
- "Built in" adds no OS sandbox. Harness and plugins can still execute local code.
