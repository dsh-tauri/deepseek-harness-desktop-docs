The desktop currently ships 13 first-party plugins as resources. Startup checks restore missing or inconsistent copies.

<Note>
  The recommended core is **0.2.0-rc.2**; the desktop's declared compatibility minimum remains **0.1.5-rc.1**. Passing the minimum check does not guarantee every plugin works on an older core; local kernel entries require **0.2.1-alpha.2 or newer** and bridge capabilities.
</Note>

## Distribution and permissions

- The current desktop `plugins.built-in` manifest is authoritative. Running Changes is no longer in the built-in set.
- Community presets are installed separately; the Extensions Skills/MCP panel has no marketplace.
- “Built in” adds no OS sandbox. Harness and plugins can still execute local code.
