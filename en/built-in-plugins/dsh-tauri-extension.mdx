## Skills

- Search, filter, enable, or disable skills; inspect content or open directories.
- Import GitHub skill repositories or add local skill directories.
- Edit skills from writable sources; check the target directory before deletion.
- **New skill** opens a blank session and prefills `/skill-creator ` without sending it.

## MCP

- Add, edit, enable, disable, or delete servers using a form or JSON.
- Import configuration from Claude Code or Codex and check connection status.
- Restart the host when a configuration change requires it.

## Data and boundaries

- Custom skills and source records live under `$DSH_HOME/skills/`; MCP configuration belongs to the current profile.
- Host routes use `/api/tauri/extension`.
- The plugin itself has no marketplace; see [plugin management](../guides/plugins) for community plugins and the marketplace.
- Skills and MCP can trigger local code execution. Verify sources and permissions before importing.
