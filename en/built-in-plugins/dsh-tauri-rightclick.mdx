`dsh-tauri-rightclick` provides context menus inside the desktop's embedded Harness UI, using Harness session and workspace services and menu components. It is not an operating-system-wide context menu.

## Where to right-click

| Target | Actions |
| --- | --- |
| Existing session row | Rename, fork, archive, copy the directory or session ID, and open the directory. Pin / unpin appears when the core provides it. |
| Workspace row | Create a session, rename the display label, open the directory, copy its path, archive sessions in bulk, or remove the workspace registration. |
| Ungrouped heading | Archive ungrouped sessions in bulk, excluding blank and already archived sessions. |
| Text, links, inputs | Copy or select all text, open or copy links, and undo, redo, cut, copy, or paste in inputs. |
| Refresh menu item | Reloads the current Harness page without restarting the local Harness service. |

Blank new sessions do not get a session menu. Unsupported targets keep the default menu. Session actions prefer the official row menu or public services. Without `pinSession` / `unpinSession`, the plugin omits pinning rather than simulating pinned state.

## Archiving is not permanent deletion

| Action | What is preserved |
| --- | --- |
| Archive one or more sessions | Keeps session records, which can be restored in [Archive Management](./dsh-tauri-archive). |
| Delete workspace | Removes only the workspace registration; keeps the project folder and session records. |
| Permanently delete sessions | Not performed by archive or workspace-removal actions here. Confirm it separately in Archive Management. |

Bulk archiving and workspace deletion show a confirmation first. Renaming a workspace changes its display label, not the directory on disk.

## Host access and compatibility boundaries

- Opening a directory uses `/api/tauri/rightclick/open/path` and the system file manager on the machine running the Harness host.
- Opening an external link uses `/api/tauri/rightclick/open/url` and that machine's default browser. Only `http` / `https` URLs are accepted, not arbitrary URL schemes.
- Loading the Web UI in another wrapper or an ordinary browser does not imply support for every action. Host routes, session services, and clipboard capabilities are still required.
- Disabling the plugin cleans up listeners and overlays. It does not edit upstream packages, the desktop shell, or other plugins' files.
