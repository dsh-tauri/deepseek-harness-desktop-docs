Tauri packages the React frontend, Rust backend, bundled plugins, and the Electron runtime into native installers. GitHub Actions runs the release pipeline.

## Local build

Prepare the toolchain in [Development setup](./setup), then run:

```bash
pnpm install --frozen-lockfile
pnpm build:plugins
pnpm typecheck
pnpm lint
node node_modules/vitest/vitest.mjs run --project unit
pnpm tauri build
```

`pnpm tauri build` runs `pnpm build:plugins` and `pnpm build` before compiling and bundling Rust together with the Electron runtime. Complete the E2E and Rust checks in [Testing and quality checks](./testing); platform bundles require a compatible OS and its signing tools.

## Release flow

The [release workflow](https://github.com/dsh-tauri/deepseek-harness-desktop/blob/main/.github/workflows/release.yml) runs for a `v*` tag, a merged `release/*` PR from the same repository, or a manual trigger. Manual runs produce `test-*` prereleases.

1. Align package, Cargo, and Tauri versions, release notes, and both documentation languages.
2. Complete frontend type checking, linting, Vitest, and cross-platform Rust checks.
3. Build Windows, both macOS architectures, and both Linux architectures in parallel; verify signing, notarization, and installation behavior.
4. A single publishing job gathers successful outputs. Prereleases are marked accordingly; only stable releases update latest.

The nightly workflow builds `main` daily as `0.0.0-nightly.<date>.<sha>`, writes two prerelease Releases, and keeps the last 10 days.

<Warning>
  Never expose signing certificates, notarization credentials, or update keys in logs,
  documentation, pull requests, or local fixtures. Use repository secrets and the
  established release workflow.
</Warning>
