## Installer types

| Platform | Installer | When to use it |
| --- | --- | --- |
| Windows | `*-setup.exe` | Default choice, NSIS installer |
| Windows | `*_x64_en-US.msi`, `*_x64_zh-CN.msi` | When MSI distribution is required, such as enterprise deployment |
| macOS | `*_aarch64.dmg` | Apple Silicon (M-series) |
| macOS | `*_x64.dmg` | Intel |
| Linux | `*_amd64.deb` | Debian, Ubuntu, and similar distributions with fuller system integration |
| Linux | `*_amd64.AppImage` | No installation required, runs as a single file |

You can also install on macOS with Homebrew:

```bash
brew install dsh-tauri-desk/desktop/deepseek-harness
```

## System requirements

| Platform | Requirement |
| --- | --- |
| Windows | Windows 10 or later |
| macOS | macOS 10.15 or later |
| Linux | Modern 64-bit distribution |

The first launch requires a network connection. After setup, normal work remains local unless a model provider, plugin, or update needs network access. Built-in plugins require Harness core **0.1.5-rc.1** or later.

## Install and launch

Run the installer you downloaded, then open **DeepSeek Harness Desktop** from your application menu.

## Platform notes

<AccordionGroup>
  <Accordion title="Windows security prompt">
    Confirm that the installer came from the official GitHub Release. The application
    uses WebView2, which is included with supported Windows versions.
  </Accordion>
  <Accordion title="macOS blocks the first launch">
    Verify the download source, then allow the application from
    **System Settings → Privacy & Security**.
  </Accordion>
  <Accordion title="Black window on Linux Wayland">
    Prefer `.deb`. If the AppImage still shows a black window, try:
    ```bash
    WEBKIT_DISABLE_COMPOSITING_MODE=1 WEBKIT_DISABLE_DMABUF_RENDERER=1 GDK_BACKEND=x11 ./Deepseek*.AppImage
    ```
  </Accordion>
</AccordionGroup>

<Note>
  Released users do not need to install Node.js, pnpm, or Docker. These tools are only
  required when developing the desktop application from source.
</Note>
