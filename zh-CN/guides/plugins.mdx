插件可以为 Harness 添加工具、UI 面板、通知与桌面集成。桌面端区分必需的内部插件、可选预设插件和社区插件。

## 插件类型

| 类型 | 分发方式 | 用户控制 |
| --- | --- | --- |
| 内部 | 随桌面安装包提供并在启动时确保存在 | 缺失时自动恢复 |
| 预设 | 首次运行时推荐，从 npm 或 GitHub 安装 | 可选，可稍后更新或移除 |
| 社区 | 手动安装或通过市场插件安装 | 先审查源码与权限 |

内部插件提供 Tauri 桥、设置 UI、模型配置页、Worktree、面板入口、Skills/MCP 管理、定时任务、Turn 级撤销、桌宠和右键菜单。定时任务在独立 Agent 会话中运行；Turn Rewind 使用私有 Git 快照，不修改用户仓库历史。Windows Minimal 修复插件在选择后从 GitHub 下载，其源码**不内置**于应用。

<Note>
  内部插件要求 Harness 内核 **0.1.5-rc.2** 或更高版本；使用更低版本的内核时这些插件不会加载。
</Note>

## 管理插件

<Steps>
  <Step title="打开插件设置">检查名称、来源、安装状态和错误信息。</Step>
  <Step title="选择操作">安装可信插件、升级旧版本或移除不再使用的可选插件。</Step>
  <Step title="按提示重启">部分宿主或 UI 集成需在 Harness 服务重新加载后生效。</Step>
</Steps>

## 恢复

插件操作被中断时，使用桌面面板显示的恢复操作。服务启动前会检查内部插件；声明或文件缺失时，
会重新链接安装包内的副本。

<Warning>安装 Harness 插件就是安装本地代码。安装前检查仓库所有者、发布历史、包内容与所需能力。</Warning>

开发者可继续阅读[插件系统架构](../architecture/plugin-system)。
