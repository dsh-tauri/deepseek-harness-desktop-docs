---
title: 手机远程访问
description: 用手机浏览器或 DSH Mobile 通过局域网与公网隧道访问电脑上的 Harness。
---

手机连接的是电脑上运行的 Harness，不是在手机本地运行内核或工具。电脑必须保持开机，Harness 服务与所用隧道必须在线。

桌面顶部**远程**提供分享二维码、链接和临时配对码。需要修改监听地址、具名隧道或撤销授权时，打开 Harness **设置 → 远程访问 → 远程访问**标签页。连接其他电脑的 SSH 用法见 [DSH Tauri Remote](../built-in-plugins/dsh-tauri-remote)。

## 同一局域网连接

1. 将手机与电脑连接到同一可信局域网，打开桌面顶部**远程 → 局域网**。
2. 点击**开启局域网分享**，等待出现可用二维码或链接；远程访问默认关闭，开启分享时会启用认证。
3. 用手机浏览器扫码或打开链接；需要配对时输入桌面显示的临时配对码。
4. 确认能看到电脑上的会话，再发送一个小型任务验证连接。

{/* <!-- [桌面远程菜单的局域网分享状态；遮盖二维码、链接与配对码](/images/mobile-remote-access-lan.webp) --> */}

链接必须是手机能访问的局域网地址，不能用 `127.0.0.1` 或 `localhost`。无法连接时，检查电脑防火墙、所选网卡和 Wi-Fi 的客户端隔离；仅绑定回环地址时，从远程访问设置改为局域网地址。

## 从外网连接

在桌面顶部**远程 → 公网隧道**点击**启用隧道**，等待隧道就绪后，用手机打开对应链接或扫描二维码。外网访问不要求两台设备在同一 Wi-Fi。

| 模式 | 用途与前提 |
| --- | --- |
| Cloudflare Quick | 免账号，自动分配随机域名；重新启动后地址可能变化，重新获取链接 |
| 具名隧道 | 在远程访问设置中填写 Cloudflare Tunnel Token 和公开主机名，并在 Cloudflare 配置该主机名的路由 |

{/* <!-- [公网隧道模式与运行状态；遮盖链接、二维码、配对码和 Tunnel Token](/images/mobile-remote-access-tunnel.webp) --> */}

先等状态变为运行中，不要分享仍在启动的入口。用完可**停止隧道**；这只关闭公网通路，不等同撤销已配对设备。

<Warning>
  分享链接、二维码、配对码和 Tunnel Token 都按凭据保管，不要发到公开聊天、截图或 Issue。远程访问不是只读：连接者可使用该实例的会话、工具与已授予的权限。保留认证，不要直接将无认证服务端口暴露到公网。
</Warning>

## 使用 DSH Mobile

DSH Mobile 用 WebView 打开电脑上的 Harness，提供**自动扫描局域网**、**扫码连接**和最近连接记录。扫码需授予相机权限，二维码须包含有效 HTTP/HTTPS 连接地址；外网使用隧道二维码，而不是局域网地址。

从[安装与下载](../installation)选择移动端资源：Android 提供 APK；iOS 当前提供未签名 IPA，需自行签名安装，不代表 App Store 上架。

自动扫描找不到主机时，先确认 Wi-Fi 与电脑分享状态，或改用扫码。连接成功后可向左滑查看连接信息；长按最近连接可重命名或删除。删除手机连接记录不等同撤销电脑端授权。

{/* <!-- [DSH Mobile 的局域网扫描、扫码连接与最近连接入口；隐藏设备地址](/images/mobile-remote-access-app.webp) --> */}

## 配对与撤销授权

- 临时配对码 **5 分钟内有效**，使用后轮换；过期时从桌面重新获取。
- 配对后设备会长期记住授权，不能把配对码过期理解为已退出。
- 在电脑的远程访问设置中点击**撤销配对授权**，会清除全部设备授权、会话和访问码，所有设备需重新配对。仅轮换永久访问码不会撤销已签发会话。
- 不再使用时关闭局域网分享与公网隧道；需要收回设备权限时同时撤销授权。
