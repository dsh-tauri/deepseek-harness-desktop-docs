DeepSeek Harness 的桌面客户端不止一种。它们都希望降低本地 Harness 的安装和使用门槛，
但在桌面技术、平台覆盖、插件策略和扩展功能上采用了不同取舍。

<Note>
  对比基于各项目截至 2026-09-11 的公开 README、仓库清单和最新 Release。
  “未确认”表示公开材料没有明确承诺，不代表项目一定不具备该能力。功能会快速变化，选择前请核对对应仓库。
</Note>

## 项目定位

### DeepSeek Harness Desktop（本项目）

一键运行 DeepSeek Harness，无需配置环境的开箱即用桌面客户端，注重原生轻量、非商业捆绑与代码库克制。
采用 Tauri 2 + React 架构，由桌面端托管运行时与插件健康，底层模型、会话与 Agent 工作流直接接轨 Harness 最新内核。
全面覆盖双端桌面与 Linux，优先巩固第一方高可用能力，将 Codex 功能完成度作为明确目标。

### anywhere-labs/dsh-desktop

[anywhere-labs/dsh-desktop](https://github.com/anywhere-labs/dsh-desktop) 把桌面壳本身实现为 DSH/Cordis 插件，
强调桌面能力与 Harness 插件生态使用同一种组合方式。它使用 Electron、固定运行特定上游版本，内置社区插件市场，
并提供 Profile 级首次设置向导、窗口材质、浏览器打开和可选局域网访问。当前 Release 面向 Windows x64 与 macOS Universal。

### dataelement/dsh-desktop

[dataelement/dsh-desktop](https://github.com/dataelement/dsh-desktop) 定位为 local-first 的 macOS/Windows Electron 客户端，
可移植 Agent preset、模型供应商、插件故障诊断和非破坏性 Safe Mode。手机访问使用独立配对桥，需桌面明确批准，
可在局域网或可选临时隧道中续接会话。当前 Release 覆盖 Windows x64、macOS Intel 与 Apple Silicon，不支持 Linux。

### Deepseek Harness EAC

[Deepseek Harness EAC](https://github.com/zouyuxuan122/Deepseek-Harness-EAC) 定位为开箱即用的一体化增强发行版。
当前主线使用 Tauri 2，并在 Harness 上预装主题、文件树、文件变更、终端、插件市场、自动压缩和插件保护等较多能力。
它提供 Windows 安装版与便携版、macOS Apple Silicon 版本，并通过较早的独立版本线维护 Linux x64 包。

## 如何理解这些差异

### 保持接近上游，不等于没有产品能力

本项目保留 Harness 的工作区、文件树、文件改动、Diff 和终端能力，同时用少量第一方插件补充桌面体验：
`dsh-tauri-worktree` 提供会话级 Git 隔离；`dsh-tauri` 提供稳定侧栏与面板入口 API（`definePanel`）；
`dsh-tauri-panel-extension` 在该入口上提供 Skills、技能仓库和 MCP 管理。

区别在于这些能力具有明确边界、协议和维护责任，而不是把大量互不相关的社区插件默认装给所有用户。
EAC 更倾向于预装完整增强工具集；本项目更倾向于维护较小、可验证的默认集合。

### 面板入口为什么重要

`definePanel` 允许插件在统一侧栏区域注册入口（`sidebar.panellist`），并把内容注册进主区域槽（`main`），
面板内容的打开、替换和关闭由宿主统一管理。
扩展插件无需复制整个侧栏或依赖易变的 DOM/CSS 结构，宿主仍负责折叠态、选中态和恢复官方会话视图。
当前 Skills/MCP 面板既是用户功能，也是该入口的第一个完整消费者。

### Tauri，还是 Electron

Tauri 项目使用系统 WebView 和 Rust 原生层，通常能获得更小的桌面壳；Electron 项目携带一致的 Chromium/Node
运行环境，更容易提供跨平台一致的浏览器能力。实际安装体积和内存还取决于捆绑的 Harness、Node 和插件，
不能仅根据框架名称判断。

### 本机回环，还是远程访问

本项目默认只监听 `127.0.0.1`。dataelement 使用独立、需桌面批准的手机配对桥；anywhere-labs 提供可选局域网暴露，
并明确警告该模式没有鉴权。这些方案的便利性与信任边界不同，不应只用“是否支持远程”一个勾选项判断。

### 恢复策略

本项目重点识别导致启动失败的插件并引导移除。dataelement 提供隔离第三方插件的 Safe Mode；EAC 强调安装前快照、
体检、修复和回滚。频繁试用社区插件的用户应优先比较恢复流程，而不只是插件数量。
