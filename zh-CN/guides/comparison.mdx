  “未确认”表示材料没有明确说明，不代表功能不存在；不同发布渠道的能力不能混用。

## 项目定位

| 项目 | 桌面技术 | 主要取舍 |
| --- | --- | --- |
| 本项目 | Tauri 2 命令与 Rust 服务层，窗口由内置 Electron / Chromium 渲染；独立 Harness 服务 | 第一方桌面增强、多内核管理；社区插件按需选择 |
| anywhere-labs/dsh-desktop | Electron；桌面本身是 DSH/Cordis 插件 | 插件式组合、Profile 向导、Agents Anywhere 手机控制 |
| dataelement/dsh-desktop | Electron | 本地优先、可移植 Agent preset、PPT 与手机配对桥 |
| DeepSeek 官方桌面端 | Electron；内置完整 Harness Web UI 与 Host | 官方公共预览；桌面与内核同步更新，插件按需启用 |

框架名称不是性能排名；安装体积、内存与响应速度还取决于运行时和插件，本文没有统一基准测试。

## 管理、插件与恢复

本项目按当前 v0.30.3 清单；官方列依据公共预览页面与当前桌面源码，未把源码版本号当作下载包版本。

| 比较项 | 本项目 | anywhere-labs | dataelement | DeepSeek 官方 |
| --- | --- | --- | --- | --- |
| Profile / 运行时 | 内置 `desktop` Profile；多内核切换、复用本地 `dsh`、CLI 注册 | Profile 向导/切换；固定 Harness | 保留 Profile 数据；固定 Harness | 专用 `desktop` Profile；内核随桌面更新，可选 CLI 注册 |
| 插件策略 | 13 个内置包（12 个桌面插件 + 共享样式包）；`dshmarket` 等为可选预设 | 桌面即插件；内置社区市场 | Harness 插件；第三方插件按需安装 | 共用 Harness 插件管理器；Creator mode 创建插件 |
| 特色管理入口 | 插件、Skills 与来源、MCP：`dsh-tauri-extension` | Profile 设置与插件 CLI | `.dshpreset` 导入/导出、模型供应商、PPT | 插件管理、运行轨迹与开发者工具 |
| Worktree / 定时任务 | 会话 Git Worktree；定时执行与运行历史 | 未确认 | 未确认 | Worktree 未确认；定时任务需启用插件，非默认开启 |
| 插件故障恢复 | 定位问题插件并引导移除；发布保护期拦截可授权重试 | 恢复助手 | 故障诊断；非破坏性 Safe Mode | 原生恢复对话框；禁用第三方插件、备份 Profile patch 后重启 |

- 本项目内核推荐 `0.2.1-rc.5`，最低 `0.2.1-rc.1`；anywhere 各渠道固定 `0.2.1-rc.3`。
- dataelement 当前清单固定 `@deepseek-ai/dsh@0.2.2-alpha.2`，README 表述与之不一致，以版本清单为准。
- 本项目内置 ID 包括 `dsh-tauri-scheduler`、`dsh-tauri-archive`、`dsh-tauri-model`、`dsh-tauri-notification`；本机 Codex/Claude 内核入口已移入弃用名单，改由预设 `dsh-third-kernel` 提供。
- 官方桌面与 CLI 共用会话、设置等产品数据，但插件启用状态与可执行依赖隔离；不等于多内核切换。

## 远程入口的区别

| 机制 | 本项目 | anywhere-labs | dataelement | DeepSeek 官方 |
| --- | --- | --- | --- | --- |
| SSH 远程主机 | 内置 `dsh-tauri-remote`；连接远端 `dsh web`，经回环隧道访问 | 未确认 | 未确认 | 未确认 |
| 手机续接 | 内置 LAN / Cloudflare 隧道与配对认证；浏览器或 DSH Mobile（Android APK / iOS TestFlight）续接 | Agents Anywhere（2.0.9 起） | 独立配对桥：LAN / 临时公网隧道 | 未确认 |

- SSH 在远端主机运行 Harness；手机桥续接桌面会话，不是同一种“远程支持”。
- anywhere 的浏览器打开不改变监听范围；另行开启 LAN 会暴露无鉴权入口，仅用于完全可信网络。
- dataelement 的 Harness 仍监听随机回环端口；公网桥需配对密码，断开手机会使移动会话失效。

## 如何选择

- 需要多内核管理、第一方面板、Worktree、定时任务或 SSH 主机连接：先看本项目，并确认正式版与 Nightly 的区别。
- 需要插件式桌面与 Agents Anywhere：看 anywhere；更重视可移植 preset、PPT 和配对手机桥：看 dataelement。
- 希望直接使用官方 Harness 桌面预览：看官方下载页，先确认操作系统与架构，再按需启用插件。

<Warning>
  Harness 与插件可执行本地代码。Profile、Worktree、Safe Mode 和插件保护不等于 OS 沙箱。
  审查安装来源、插件与网络暴露方式；不可信任务应使用系统级隔离。
</Warning>
