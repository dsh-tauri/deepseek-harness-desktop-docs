## 项目定位

| 项目 | 桌面技术 | 主要取舍 |
| --- | --- | --- |
| 本项目 | Tauri 2 + React；独立 Harness 服务 | 第一方桌面增强、运行时管理；社区插件按需选择 |
| anywhere-labs/dsh-desktop | Electron；桌面本身是 DSH/Cordis 插件 | 插件式组合、Profile 向导、Agents Anywhere 手机控制 |
| dataelement/dsh-desktop | Electron | 本地优先、可移植 Agent preset、PPT 与手机配对桥 |
| DeepSeek 官方桌面端 | Electron；内置完整 Harness Web UI 与 Host | 官方公共预览；桌面与内核同步更新，插件按需启用 |

框架名称不是性能排名；安装体积、内存与响应速度还取决于运行时和插件，本文没有统一基准测试。

## 管理、插件与恢复

本项目按当前 v0.20.0-beta.1 清单；官方列依据公共预览页面与当前桌面源码，未把源码版本号当作下载包版本。

| 比较项 | 本项目 | anywhere-labs | dataelement | DeepSeek 官方 |
| --- | --- | --- | --- | --- |
| Profile / 运行时 | 原生 Profile；多内核切换、复用本地 `dsh`、CLI 注册 | Profile 向导/切换；固定 Harness | 保留 Profile 数据；固定 Harness | 专用 `desktop` Profile；内核随桌面更新，可选 CLI 注册 |
| 插件策略 | 第一方内置；`dshmarket` 等为可选预设 | 桌面即插件；内置社区市场 | Harness 插件；第三方插件按需安装 | 共用 Harness 插件管理器；Creator mode 创建插件 |
| 特色管理入口 | Skills/来源管理与 MCP 配置：`dsh-tauri-extension` | Profile 设置与插件 CLI | `.dshpreset` 导入/导出、模型供应商、PPT | 插件管理、运行轨迹与开发者工具 |
| Worktree / 定时任务 | 会话 Git Worktree；定时执行与运行历史 | 未确认 | 未确认 | Worktree 未确认；定时任务需启用插件，非默认开启 |
| 插件故障恢复 | 定位问题插件并引导移除 | 恢复助手 | 故障诊断；非破坏性 Safe Mode | 原生恢复对话框；禁用第三方插件、备份 Profile patch 后重启 |

- 本项目内核推荐 `0.2.0-rc.2`，最低 `0.1.5-rc.1`；anywhere 当前三渠道固定 `0.2.0-rc.2`。
- dataelement 清单与 v0.10.0 发布说明为 `0.1.7-rc.2`，README 仍写 rc.1，以版本清单为准。
- 本项目当前 ID 包括 `dsh-tauri-scheduler`、`dsh-tauri-archive`、`dsh-tauri-model`；Beta 新增 `dsh-tauri-notification` 原生通知。
- 官方桌面与 CLI 共用会话、设置等产品数据，但插件启用状态与可执行依赖隔离；不等于多内核切换。

## 远程入口的区别

本节本项目列于 2026-10-14 按当前源码补充；其他项目与上方版本表仍为 2026-09-30 的核对结果，并非全表重新调研。

| 机制 | 本项目 | anywhere-labs | dataelement | DeepSeek 官方 |
| --- | --- | --- | --- | --- |
| SSH 远程主机 | 内置 `dsh-tauri-remote`；连接远端 `dsh web`，经回环隧道访问 | 未确认 | 未确认 | 未确认 |
| 手机续接 | 内置 LAN / Cloudflare 隧道与配对认证；浏览器或 DSH Mobile 续接 | Agents Anywhere（2.0.9 起） | 独立配对桥：LAN / 临时公网隧道 | 未确认 |

- SSH 在远端主机运行 Harness；手机桥续接桌面会话，不是同一种“远程支持”。
- anywhere 的浏览器打开不改变监听范围；另行开启 LAN 会暴露无鉴权入口，仅用于完全可信网络。
- dataelement 的 Harness 仍监听随机回环端口；公网桥需配对密码，断开手机会使移动会话失效。

## 如何选择

- 需要多内核管理、第一方面板、Worktree、定时任务或 SSH 主机连接：先看本项目，并确认正式/Beta 渠道。
- 需要插件式桌面与 Agents Anywhere：看 anywhere；更重视可移植 preset、PPT 和配对手机桥：看 dataelement。
- 希望直接使用官方 Harness 桌面预览：看官方下载页，先确认操作系统与架构，再按需启用插件。

<Warning>
  Harness 与插件可执行本地代码。Profile、Worktree、Safe Mode 和插件保护不等于 OS 沙箱。
  审查安装来源、插件与网络暴露方式；不可信任务应使用系统级隔离。
</Warning>
