`dsh-tauri-turnrewind` 为每个 Agent 回合建立私有 Git 快照，并在会话尾部显示文件变更卡片。它不会修改用户仓库的 HEAD、分支、index、stash 或提交历史。

## 用户可见功能

- 回合结束后显示已编辑文件数量与 `+N -M` 行数。
- 在冲突检查通过时一键撤销该回合的新增、修改和删除。
- 文件清单最多显示三行，可展开查看其余文件。
- 在支持侧边栏文件能力的新内核中，点击文件可打开应用内预览；“审核”可打开工作区文件树。
- 工作区不是 Git 仓库时不显示噪音卡片；Git 缺失、危险路径或快照过期等可操作诊断仍会显示。

## 数据与边界

快照存放在 `$DSH_HOME/dsh-tauri-turnrewind/` 下的私有仓库和会话账本中。每个工作区最近 50 个回合保持可撤销，账本最多保留 200 条记录。单文件、单回合和快照均有大小/数量上限，超出范围的路径会在卡片中提示。

撤销前会检查回合之后是否发生新的文件改动；存在冲突时不会覆盖任何文件。非 Git 工作区、嵌套仓库和被排除的大文件不在撤销范围内。

<Warning>
  撤销会改变工作区文件。执行前请检查冲突提示；该插件不是备份系统，也不会提供 redo。
</Warning>

## 兼容性

插件根据运行时能力而不是版本号选择文件预览和审核按钮。旧内核缺少应用内侧边栏能力时，这些入口会隐藏或降级，不会把路径交给系统程序。
