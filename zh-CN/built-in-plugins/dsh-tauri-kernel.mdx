`dsh-tauri-kernel` 已移入清单的弃用名单（`plugins.depercated`），不再随桌面资源分发。接入本机 Codex 与 Claude Code 的方式改由社区预设 **DSH Third Kernel**（`dsh-third-kernel`）提供。

## 安装

1. 在首次运行向导或**配置 → 插件 → 打开预设**中勾选 **DSH Third Kernel**。
2. 按提示安装并重启 Harness，确认插件加载成功。
3. 在该电脑的终端确认 `codex --version` 或 `claude --version` 可用，并完成对应 CLI 登录。

预设不计入内置插件数量，版本与兼容范围由清单中该预设声明的内核区间决定。安装与卸载步骤见[插件管理](../guides/plugins)。

## 会话与边界

- 选择内核会新建会话，不切换当前会话的内核。
- 会话绑定原生内核后不能更换；模型与推理深度调整只影响下一完整轮次。
- 这些 CLI 使用自己的凭据与服务，不能用 Harness 的 DeepSeek 模型配置代替。
- CLI 仍可执行命令、修改文件和访问网络；插件与 Profile 不提供额外的操作系统沙箱。
