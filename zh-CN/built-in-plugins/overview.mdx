DeepSeek Harness Desktop 通过少量第一方插件连接 Harness 与 Tauri 桌面壳。这些插件随安装包提供，
启动前会检查其声明与文件；缺失或不一致时，桌面端会从内置资源恢复。

<Note>
  内置插件要求 Harness 内核 **0.1.5-rc.1** 或更高版本。更低版本的内核不提供插件所需的客户端 API，
  面板类插件无法加载。
</Note>

## 为什么是内置插件

这些能力需要与桌面窗口、导航、Profile、工作区或宿主文件系统配合，并且必须与桌面端版本共同测试。
把它们作为插件实现，可以保留 Harness 的 host half/client half 架构，同时让桌面端承担明确的维护和恢复责任。

<Note>
  “内置”表示随桌面安装包分发并自动确保存在，不表示插件拥有额外的操作系统沙箱。
  它们仍在 Harness 与桌面端允许的权限范围内运行。
</Note>

源码位于桌面仓库的 [`packages/`](https://github.com/dsh-tauri-desk/deepseek-harness-desktop/tree/main/packages) 目录。
