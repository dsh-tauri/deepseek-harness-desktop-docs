<Note>
  推荐内核为 **0.2.0-rc.2**；桌面声明的兼容最低版本仍为 **0.1.5-rc.1**。最低版本检查不保证所有插件在旧内核上均可用；本机内核入口要求 **0.2.1-alpha.2 或更新版本**及桥接能力。
</Note>

## 分发与权限

- 清单以当前桌面 `plugins.built-in` 为准；旧 Running Changes 不再属于内置集合。
- 社区预设另行安装；扩展插件的 Skills/MCP 面板不包含市场。
- “内置”不提供额外操作系统沙箱。Harness 与插件仍可执行本地代码。
