`dsh-tauri-model-config` 扩展桌面端的**设置 → 模型**页，提供模型参数配置与自动补全。

{/* <!-- [模型设置页中的容量输入、图片输入与思考模式开关](/images/zh-CN/dsh-tauri-model-config.png) --> */}

## 功能

- 配置模型的上下文与输出上限、图片输入和思考档位。
- 通过**获取配置**或**自动配置所有模型**补全模型参数。
- 为兼容端点提供**关闭 Developer 角色**选项，仅在路由显式使用 `openai-completions` 时显示。
- 通过**打开配置文件**在外部编辑器中查看和修改模型配置；文件不存在时打开所在目录。

## 自动配置

单行的**获取配置**只补空缺，不覆盖已填写的值。**自动配置所有模型**会用端点返回的上下文与输出上限覆盖旧值，未返回的字段保持不动。

容量优先取自提供方端点；图片输入与思考能力参考在线能力表，并在离线时回退到缓存或模型命名规则。自动结果可能不准确，可在高级设置中手动调整。

## 数据与边界

- 插件替代官方模型设置页，不应与官方入口同时启用。
- 插件会请求提供方端点、下载并缓存能力表，以及读写 Harness 设置；不提供额外的操作系统沙箱。
- **打开配置文件**使用 `$DSH_HOME/settings.yaml`，未设置时使用 `~/.dsh/settings.yaml`，不会识别 Profile 中自定义的 `settings-file` 路径。
