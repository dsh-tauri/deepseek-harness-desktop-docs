`dsh-tauri` 是桌面壳的基础桥接插件。它的 host half 不添加业务行为；client half 运行在 Harness iframe 中，
把原生窗口导航转换为 Harness 布局与浏览器历史操作。

## 用户可见能力

- 原生顶部栏可以展开或收起 Harness 侧边栏。
- 后退与前进按钮控制嵌入页面的浏览历史。
- 按钮会根据历史边界自动禁用。
- 官方重复的折叠控件会隐藏，避免两个入口表达同一操作。

## 状态同步

插件向桌面宿主回报侧边栏折叠状态、是否可以后退和是否可以前进。插件自身发生异常时也会报告宿主，
避免原生按钮保留在界面中却静默失效。

## 面板入口

client half 还提供桌面侧栏的面板入口：插件调用 `definePanel(ctx, entry)` 注册一个 `PanelEntry`
（`id`、`label`、`icon`、`render`，可选 `order` 与 `locale`）。条目注册进侧栏面板列表槽
`sidebar.panellist`，`render` 注册进主区域槽 `main`；返回的 `PanelHandle` 提供 `select()`、
`close()` 和 `dispose()`。`dsh-tauri-panel-extension` 与 `dsh-tauri-panel-scheduler` 都通过该入口注册面板。

该入口与其他内置插件共用同一基线，要求 Harness 内核 **0.1.5-rc.2** 或更高版本。旧版 `dsh-tauri-panel` 的 `panel.protocol`
反射服务与 `sidebar.panel.action` 槽已随包移除，不提供兼容路径。

## 边界

`dsh-tauri` 只负责导航消息、面板入口与状态，不管理 Profile、内核、插件安装或文件系统。
缺少该插件时，Harness 本身仍可运行，但桌面顶部栏不会显示依赖消息桥的导航按钮。
