`dsh-tauri` 连接原生桌面壳、Harness 宿主与内嵌客户端。桌面导航、账号授权浏览器和其他插件的原生调用都依赖这层桥接。

## 从桌面入口使用 Harness

| 入口 | 结果 |
| --- | --- |
| 顶部栏侧栏开关 | 展开或收起 Harness 侧栏，并回报折叠状态；隐藏重复的客户端折叠控件。 |
| 文件 → 新聊天 | 调用 Harness 的会话入口。 |
| 文件 → 打开文件夹 | 选择目录、创建工作区，并在该工作区打开会话。 |
| 显示键盘快捷键 | 打开官方快捷键弹层；核心提供快捷键目录时，菜单提示会跟随自定义键位更新。 |
| `Ctrl` / `Cmd` + `+`、`-`、`0` | 即使焦点在 iframe 中，也将缩放操作交给原生窗口处理。 |
| 账号登录 | 账号能力可用时，在系统默认浏览器打开 `http` / `https` 授权地址。 |

## 给插件提供的接口

| 导入入口 | 提供的能力 |
| --- | --- |
| `dsh-tauri` | 宿主运行时、`defineRoutes`、`defineService` 及进程、文件和系统打开工具。宿主侧并非空实现。 |
| `dsh-tauri/client` | 布局与会话适配器、父窗口消息、Tauri `invoke` / `listen` 和面板注册。 |

面板通过 `definePanel(ctx, entry)` 注册。`PanelEntry` 包含 `id`、`label`、`icon`、`render`，可选 `order` 与 `locale`；入口注册到 `sidebar.panellist`，内容注册到 `main`。返回的 `PanelHandle` 提供 `select()`、`close()` 和 `dispose()`。

当前的 [`dsh-tauri-extension`](./dsh-tauri-extension) 与 [`dsh-tauri-scheduler`](./dsh-tauri-scheduler) 使用这一入口。已移除的 `dsh-tauri-panel` 的 `panel.protocol` 与 `sidebar.panel.action` 不提供兼容路径。

窗口由 `tauri-runtime-electron` 在 Electron 中承载；宿主命令、CSP 与 ACL 仍在 Rust 侧，内嵌客户端通过父窗口消息访问白名单命令。

## 兼容与安全边界

- 当前桌面推荐 Harness **0.2.1-rc.5**，接受的最低版本为 **0.2.1-rc.1**。最低版本不保证每项 API 都存在；适配取决于实际服务与能力探测。
- 宿主仅在桌面注入 `DSH_TAURI_EMBEDDED=1` 时启用内嵌载体鉴权适配。独立启动的 `dsh web` 继续使用 browser-session 鉴权。
- Tauri 调用经父窗口消息转发。桌面壳核对 iframe 来源与 origin，只执行白名单命令；缺少宿主桥时调用会失败，不会自动获得其他原生权限。
- 客户端桥只在嵌入环境启用。插件缺失或初始化失败时，依赖它的桌面导航与原生调用没有通用替代路径。

<Warning>
  消息校验不是执行沙箱。Harness 和插件可以执行本地代码；Profile 不是操作系统沙箱。
</Warning>
