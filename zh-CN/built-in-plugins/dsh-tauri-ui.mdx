`dsh-tauri-ui` 提供桌面设置侧栏、会话入口适配和共享 UI 组件。设置内容仍由 Harness 与各插件注册，不另建一份设置数据模型。

## 打开设置并返回会话

<Steps>
  <Step title="打开设置">从 Harness 的设置入口打开侧栏，使用搜索筛选设置分区。</Step>
  <Step title="选择分区">侧栏通过 `settings.section` 呈现官方设置与插件设置，并随语言和注册内容更新。</Step>
  <Step title="返回应用">关闭侧栏后恢复内容列与侧栏交互。设置打开期间，背景内容和 Better Sidebar 不可操作。</Step>
</Steps>

设置入口注册在 `sidebar.settings`，侧栏渲染在 `shell.overlay`。桌面宿主也可用 `dsh://settings:open` 消息直接打开指定分区。

## 会话体验

| 入口 | 行为 |
| --- | --- |
| 侧栏新建会话、未分组行的 `+` | 能力可用时创建未分组会话，工作目录由宿主解析为 `$DSH_HOME/ungrouped`，不关联项目工作区。 |
| 起始页工作区选择 | 可选择工作区，或在支持时选择未分组。 |
| 输入区继续任务 | 输入为空、会话已停止且上一轮以 `aborted`、`error` 或 `interrupted` 结束时，提供继续按钮。 |
| IM 面板 | 桌面 iframe 中的 `dsh-im` 提供客户端服务时，显示独立面板并收起重复的设置入口；服务撤下后恢复。 |

## 按能力降级

降级取决于实际 renderer、适配器和服务能力，不能仅凭内核版本推断所有入口都可用。

| 缺少的能力或条件 | 处理方式 |
| --- | --- |
| 通用 `SlotOutlet` 不可用，或被识别为移动设备 | 不注册桌面设置侧栏，保留官方设置对话框。 |
| `composer.workspace-less` 不可用 | 保留官方工作区选择和按钮行为，不强行创建未分组会话。 |
| 未分组目录路由不可用 | 回退到核心默认工作目录并告警，不阻止新建会话。 |
| 快捷键目录、会话事件或 IM 服务不可用 | 不显示对应的快捷键提示、继续按钮或 IM 面板。 |

<Note>
  这里是嵌入式 Harness 的设置，不是原生桌面 Configuration。Profile、内核和运行时管理仍属于桌面壳；未分组会话也不是文件访问沙箱。
</Note>
