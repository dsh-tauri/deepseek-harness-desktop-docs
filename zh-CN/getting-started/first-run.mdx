title: 首次运行
description: 准备本地运行时、选择插件并首次打开 Harness。
---

首次启动需要准备本地 Harness 服务，再把它的 Web 界面加载到桌面窗口。保持网络连接，不要在下载或校验期间关闭应用。

<Steps>
  <Step title="准备依赖">
    桌面端检查兼容的运行时；需要时下载托管 Node.js、pnpm 和预构建 Harness 内核。受支持的下载可使用区域回退来源。
  </Step>
  <Step title="选择可选预设">
    向导提供 6 个社区预设。DSH Market、DSH Better Sidebar、DSH Rewind 默认选中；可取消或跳过，稍后在插件管理中安装。完整列表见[插件管理](../guides/plugins)。
  </Step>
  <Step title="打开 Harness">
    首次安装创建并使用 `tauri` 档案。服务默认仅监听本机，首选地址为 `http://127.0.0.1:3080`；端口占用时会使用其他可用端口。
  </Step>
  <Step title="配置模型">
    在 Harness **设置 → 模型**中添加供应商凭据，回到会话选择模型并发送小型测试任务。
  </Step>
</Steps>

## 验证设置

窗口应显示 Harness 会话界面。正式版默认启用 [CLI 集成](../guides/cli-integration)；打开一个**新终端**运行：

```bash
dsh --help
```

<Note>
  本机服务默认不对外分享。用手机访问时，从顶部**远程**开启带认证的局域网分享或公网隧道，见[手机远程访问](../guides/mobile-remote-access)；连接其他电脑见[远程访问插件](../built-in-plugins/dsh-tauri-remote)。不要将无认证的服务直接暴露到公网。
</Note>

下载或启动失败时阅读[故障排除](../help/troubleshooting)；模型配置步骤见[配置模型](./configure-model)。
