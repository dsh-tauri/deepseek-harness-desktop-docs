## 捆绑版（Bundle）

上方版本选择器单独列出该版本的 **Bundle** 下载：

| 平台 | Bundle 安装包 |
| --- | --- |
| Windows x64 | `Deepseek.Harness.Desktop_Bundle_0.19.1.exe` |
| macOS Apple Silicon | `Deepseek.Harness.Desktop_Bundle_0.19.1_aarch64.dmg` |
| macOS Intel | `Deepseek.Harness.Desktop_Bundle_0.19.1_x64.dmg` |
| Linux x64（Debian / Ubuntu） | `Deepseek.Harness.Desktop_Bundle_0.19.1.deb` |

Bundle 随包携带运行时、Harness 与内置插件，减少首次启动下载；模型访问与后续更新仍可能需要联网。所选版本没有 Bundle 时，上方不会显示该列表。

## 系统与安装包

以下为实际发布资源与系统要求：

| 平台 | 要求与架构 | 安装包 |
| --- | --- | --- |
| Windows | Windows 10+、WebView2；x64 | `.exe` / `_x64_en-US.msi` / `_x64_zh-CN.msi` |
| macOS | macOS 12+；Web 界面需 Safari 17.4+ 能力；Apple Silicon / Intel | `_aarch64.dmg` / `_x64.dmg` |
| Linux | x64；WebKit2GTK 4.1 运行库 | `.deb` / `.AppImage` |

架构和安装包类型以所选版本的实际资源为准。Git 工作树等 Git 功能还需要系统安装 Git。

macOS 也可通过 Homebrew 安装：

```bash
brew install dsh-tauri/desktop/deepseek-harness
```

## 安装并启动

1. 运行安装包；AppImage 需先允许文件执行。
2. 从应用菜单打开 **DeepSeek Harness Desktop**。
3. 保持网络和应用开启，按[首次运行](./getting-started/first-run)完成依赖安装。

模型请求、插件安装和更新仍可能需要联网。

## 平台问题

<AccordionGroup>
  <Accordion title="Windows 安全提示或缺少 WebView2">
    先确认安装包来自官方 Release。若缺少 WebView2，安装 Microsoft 提供的 WebView2 Runtime 后重试。
  </Accordion>
  <Accordion title="macOS 阻止首次启动">
    验证下载来源后，在**系统设置 → 隐私与安全性**中允许应用运行。系统版本满足最低要求时，也需确认 WebView 的兼容能力。
  </Accordion>
  <Accordion title="Linux Wayland 黑屏">
    可先尝试 `.deb`。AppImage 仍然黑屏时尝试：
    ```bash
    WEBKIT_DISABLE_COMPOSITING_MODE=1 WEBKIT_DISABLE_DMABUF_RENDERER=1 GDK_BACKEND=x11 ./Deepseek*.AppImage
    ```
    更多启动、权限和显示问题见[故障排除](./help/troubleshooting)。
  </Accordion>
</AccordionGroup>
