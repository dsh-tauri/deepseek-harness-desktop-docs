## 安装包类型

| 平台 | 安装包 | 适用场景 |
| --- | --- | --- |
| Windows | `*-setup.exe` | 默认选择，NSIS 安装程序 |
| Windows | `*_x64_en-US.msi`、`*_x64_zh-CN.msi` | 需要 MSI 分发时使用，例如企业部署 |
| macOS | `*_aarch64.dmg` | Apple Silicon（M 系列） |
| macOS | `*_x64.dmg` | Intel 芯片 |
| Linux | `*_amd64.deb` | Debian、Ubuntu 等发行版，系统集成更完整 |
| Linux | `*_amd64.AppImage` | 免安装，单文件运行 |

## 系统要求

| 平台 | 要求 |
| --- | --- |
| Windows | Windows 10 或更高版本 |
| macOS | macOS 10.15 或更高版本 |
| Linux | 现代 64 位发行版 |

首次启动需要网络：应用会下载兼容的 Node.js 运行时和预构建 Harness 内核。内置插件要求 Harness 内核 **0.1.5-rc.1** 或更高版本。

<Note>
  安装包直接来自 GitHub Releases，本页不镜像也不缓存文件。接口受限时，可以从[发布页面](https://github.com/dsh-tauri-desk/deepseek-harness-desktop/releases)手动选择。
</Note>

安装完成后继续阅读[首次运行](./getting-started/first-run)，或查看[内核与 Profile](./guides/profiles-and-cores)。
