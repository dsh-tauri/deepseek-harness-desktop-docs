Tauri 将 React 前端、Rust 后端和内置资源打包成平台原生安装程序。正式版本由 GitHub Actions 构建以确保可复现性。

## 本地构建

```bash
pnpm install --frozen-lockfile
pnpm typecheck
pnpm lint
pnpm test -- --run
pnpm tauri build
```

`pnpm tauri build` 会先执行配置的前端构建，再编译并打包 Rust 应用。平台包只能在兼容系统上构建，并需要对应签名工具。

## CI 产物

当前公开版本为 `v0.11.3`（2026-09-10）。Release 页面实际提供以下文件：

| 平台 | 产物 |
| --- | --- |
| Windows x64 | `x64-setup.exe`、英文与简体中文 `.msi` |
| macOS Apple Silicon | `aarch64.dmg` |
| macOS Intel | `x64.dmg` |
| Linux x64 | `amd64.AppImage`、`amd64.deb` |

这些文件证明当前 Release 的分发覆盖范围；不要据此推断未列出的架构。

## 发布流程

<Steps>
  <Step title="准备版本">对齐 package 与 Tauri 元数据、发布说明和用户文档。</Step>
  <Step title="运行质量门禁">完成前端类型检查、lint、Vitest 与跨平台 Rust 矩阵。</Step>
  <Step title="构建平台产物">发布工作流并行构建 Windows、两种 macOS 架构和 Ubuntu 22.04。</Step>
  <Step title="验证信任元数据">macOS 验证签名、stapling 与 Gatekeeper；其他签名产物执行对应验证。</Step>
  <Step title="发布 GitHub Release">汇总产物并为 `v*` 版本发布 Release。</Step>
</Steps>

<Warning>不得在日志、文档、Pull Request 或 fixture 中暴露签名证书、公证凭据或更新密钥。</Warning>

当前公开版本只提供 Linux x64 产物；构建并验证对应产物前，不要声明支持 Linux ARM。
